Privacy

What this website collects

This policy covers the public marketing site at mockforge.dev. It is intentionally short because the site is static: it has no user accounts, no comment forms, no advertising, and no server-side sessions.

Analytics

This site does not run analytics or tracking scripts and sets no cookies. Like any web server, our static host (GitHub Pages) may keep standard request logs such as IP address and user agent for security and abuse prevention. Web fonts are served by Google Fonts, which receives a normal request when a page loads.

Local storage

The only value this site stores in your browser is a single theme key in localStorage that remembers whether you chose light or dark mode. It never leaves your device and is not shared with anyone.

Data we do not collect

This site does not ask for your name, email address, or payment details, does not run third-party ad networks, and does not sell or share visitor data. The open-source MockForge software runs on your own infrastructure; when you use it locally, no data is sent to us.

MockForge Cloud

The hosted cloud application at app.mockforge.dev is a separate service with its own account data handling, described during sign-up. Questions about cloud data can go to privacy@mockforge.dev.

Questions

If you have questions about this policy, email privacy@mockforge.dev or see the contact page.
