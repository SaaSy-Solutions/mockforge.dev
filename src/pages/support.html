Get help with MockForge

Choose the channel that fits your question. The FAQ and documentation cover installation and configuration.

Usage questions, bugs, and feature requests

Use the public GitHub issue tracker. For a bug, include your MockForge version, protocol, expected behavior, and a small specification or configuration that reproduces it. Remove credentials and personal data before posting.

Cloud accounts and billing

Email support@mockforge.dev for account, billing, or hosted mock questions. Include the affected workspace and what you were trying to do.

Security reports

Report suspected vulnerabilities privately to security@mockforge.dev. See the Trust page for security information.

Other inquiries

For enterprise, privacy, and legal contacts, visit Contact.
