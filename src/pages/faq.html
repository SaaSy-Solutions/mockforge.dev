Frequently asked questions

Start here for local development and testing. For plan details, see pricing.

Is MockForge open source?
Yes. MockForge is available under MIT or Apache-2.0. See the source repository and licenses.
Do I need a Cloud account to run it?
You can run the CLI on your own machine without a Cloud account. Follow the installation guide to get started.
Which API protocols can I mock?
MockForge supports HTTP APIs, gRPC, GraphQL, WebSocket, and messaging protocols. Available commands depend on the features enabled in your build. Check the protocol documentation for setup and configuration.
Can I use it in CI?
Yes. Run MockForge alongside your tests and point your application at its local endpoints. Keep your specification and configuration in version control so the same setup can run locally and in CI.
Where can I get help?
The Support page explains how to report a bug, ask about a Cloud account, or contact the team privately.
